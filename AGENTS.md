# Communication Rules
- Explain everything in the simplest possible way.
- Use simple English.
- Avoid technical jargon unless necessary. Explain technical terms in 1 simple sentence.
- Keep sentences short.
- Use bullet points instead of long paragraphs.
- Give step-by-step instructions.
- Include small examples whenever possible.
- Recommend the best option first and explain why.
- End with a short summary in 2-3 sentences.
